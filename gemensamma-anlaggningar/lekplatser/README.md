# Föreningens lekplatser

[Objektregistret](register.yaml) omfattar lekplatserna på 50-, 60- och 70-gården samt den separata gunglekplatsen på 60-gården. Gungställningen med två däckgungor och en babysits har platskoppling till den separata gunglekplatsen, bekräftat av beställaren.

[Besiktningshistoriken 2012–2026](../../besiktningar/lekplatser/README.md) visar vilka protokoll som täcker respektive plats, historiska fel, klassningar och identifieringsbegränsningar. En rapport kan täcka flera platser. Historiska anmärkningar är inte automatiskt aktuella fel och senare rapporter bevisar inte i sig avhjälpande.
