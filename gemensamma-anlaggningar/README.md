## Dokumentationsprincip

Varje relevant fysisk anläggning eller utrustning ska kunna identifieras som ett objekt.

För utrustning som finns i flera exemplar ska de enskilda enheterna kunna särskiljas när det behövs för att följa exempelvis underhåll, fel, byten eller kontroller.

Objektets dokumentation kan innehålla:

- Objekt-ID
- Benämning
- Placering
- Typ och utförande
- Installations- eller byggår, om känt
- Aktuell status
- Underhållshistorik
- Service och kontroller
- Relaterade objekt
- Hänvisningar till originaldokument

Uppgifter som ännu inte är verifierade ska inte presenteras som fakta.
