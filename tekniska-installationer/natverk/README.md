# Nätverks- och lagringsutrustning

[register.yaml](register.yaml) beskriver tillgångar och deras inköps- och installationshistorik. Uppgifterna kommer från fakturor och beställarens kompletteringar. Teknisk konfiguration och drift hör till Bogesholm-Server.

UNVR G2 i kontoret innehåller två individuellt registrerade WD Purple PRO-diskar. SNMP-kortet från faktura 9003754192 hör till UPS i switchrummet i miljöhuset på 60-gården. Ett annat kort i kontorets UPS har inte kopplats till denna faktura.

Serienummer och garantiuppgifter som saknas lämnas okända. Varken installerad utrustning eller historisk installationsuppgift innebär att aktuell driftstatus har verifierats.
